Email OTP authentication setup
- Apply api/migrations/001_email_otp.sql to the existing database before restarting the API. New database setups can import the updated api/schema.sql.
- Configure EMAIL_HOST, EMAIL_PORT, EMAIL_USER, EMAIL_PASS, and EMAIL_FROM in the API environment. The API does not issue a session until the email code is verified.
- Registration codes expire after 10 minutes. Login requires a fresh code on every password sign-in.
